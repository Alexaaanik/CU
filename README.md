# Genotek: Скрининг колоректального рака по микробиому кишечника

Решение кейса по классификации колоректального рака (1 — КРР, 0 — контроль) по shotgun-метагеномным профилям (849 видов `mOTU_v2_`) и клиническим ковариатам.

**Метрики качества:**
- **OOF ROC-AUC (5-Fold Stratified CV):** `0.8849`
  - 4 когорты разработки (AUS, CHI, FRA, GER): `0.9013`
  - Когорта США (USA Specialist): `0.7639`
- **Public Leaderboard ROC-AUC:** `0.8783`

---

## Запуск решения (для жюри и оргкомитета)
Код решения полностью автономен и не требует ручной установки пакетов через терминал:

1. Откройте файл `solution_genotek_08783.ipynb` в JupyterLab, VS Code, Kaggle или Colab.
2. Нажмите **Kernel → Restart & Run All** (или последовательно выполните ячейки сверху вниз).
3. Ноутбук автоматически:
   - Подтянет необходимые зависимости (если они отсутствуют в среде);
   - Выполнит 5-кратную кросс-валидацию и напечатает OOF ROC-AUC = `0.8849`;
   - Обучит финальный ансамбль на всех 415 образцах;
   - Сохранит файл `submission.csv` и **в последней ячейке выведет итоговую таблицу предсказаний** (160 строк, `sample_id` + `label`).

## Ключевая логика решения
1. **Научный базис:** 4 метаанализа (*Zeller et al., 2014; Wirbel et al., 2019; Thomas et al., 2019; Piccinno et al., 2025*). Учёт орально-кишечной оси (*Fusobacterium, Parvimonas, Peptostreptococcus*), бутиратной защиты (*Faecalibacterium, Roseburia, R. bromii*) и мукозальных маркеров воспаления (*R. gnavus, B. fragilis, C. leptum*).
2. **Защита от утечек и батч-эффектов:**
   - Полное удаление `library_size` (глубины прочтения) из-за разнонаправленного перекоса между странами.
   - Нормировка в относительные доли $P = X / \sum X$ и композиционное CLR-преобразование.
   - Полное исключение `age` из движка США из-за отсутствия возрастного перекоса в когорте США (60.4 vs 60.0 лет).
3. **Архитектура Dual-Engine:** 4-сидовый ансамбль CatBoost с разделением на **Global Engine** (биологические гильдии, взаимодействия с возрастом, CLR топ-70 видов) и **USA Specialist** (без возраста, с мукозальной панелью).
4. **Отбор признаков:** Ранговый критерий кросс-когортной стабильности знака эффекта $|\mu| - 0.20\sigma$ раздельно по всем 5 странам.
